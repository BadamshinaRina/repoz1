# ⚔️ RPG Battle Arena

Консольная RPG-игра на Java с пошаговыми боями, торговлей и системой классов.

## 🎮 Особенности

- **3 класса**: Воин (танк), Лучник (ловкач), Маг (дамагер)
- **Боевая система**: пошаговые сражения в отдельном потоке, критические удары, уникальные способности
- **Монстры**: Скелет и Гоблин (50% шанс встречи)
- **Торговля**: покупка зелий и эликсиров у NPC
- **Прогрессия**: получение опыта и золота за победы

## 🚀 Запуск

```bash
javac *.java
java Game
🛠️ Технологии
Java, ООП, многопоточность, Collections Framework

📁 Структура
Game.java - главный класс

Battle.java - логика боя (Thread)

Character.java + классы-наследники (Warrior, Archer, Mage, Skeleton, Goblin)

Merchant.java - торговец

Интерфейсы: Fighter, Buyer, Seller

# ⚔️ RPG Battle Arena

Console-based RPG game in Java with turn-based combat, trading, and character classes.

## 🎮 Features

- **3 classes**: Warrior (tank), Archer (agile), Mage (damage dealer)
- **Combat**: turn-based battles in separate thread, critical hits, unique abilities
- **Monsters**: Skeleton and Goblin (50% spawn chance)
- **Trading**: buy potions and elixirs from NPC
- **Progression**: earn experience and gold from victories

## 🚀 Quick Start

```bash
javac *.java
java Game
🛠️ Tech Stack
Java, OOP, multithreading, Collections Framework

📁 Structure
Game.java - main class

Battle.java - battle logic (Thread)

Character.java + subclasses (Warrior, Archer, Mage, Skeleton, Goblin)

Merchant.java - trader

Interfaces: Fighter, Buyer, Seller
